**CAMPUSEVENT: COLLEGE EVENT NOTIFICATION AND REGISTRATION SYSTEM**

**PROJECT OVERVIEW**

CampusEvent is a Business Analysis Case Study focused on improving college event communication and registration.

The project addresses the problem of scattered event information across WhatsApp groups, emails, class representatives, and notice boards.

The proposed solution provides a centralized system where students can discover events, receive notifications, view event details, and register for events.

**PROJECT DETAILS**

• Project Type: Business Analysis Case Study

• Domain: Education and College Management

• Role: Business Analyst

**BUSINESS PROBLEM**

Students may miss college events because information is shared through multiple communication channels.

The proposed system aims to centralize event information, improve notifications, reduce missed registration deadlines, and simplify event management.
